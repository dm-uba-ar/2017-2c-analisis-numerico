# Laboratorio

\

- Estará disponible algún laboratorio del Departamento de Computación
  para las clases prácticas. Los alumnos pueden usar cualquier laboratorio
  fuera del horario de la materia, siempre y cuando no esté siendo usado por
  otra materia. Pueden pedir a los administradores del Departamento de
  Computación que les den un usuario para poder usar las computadoras e
  imprimir gratis. De todas formas, la materia va a tener un usuario
  propio.\

- Es recomendable el uso de pendrives o bien el envío de lo trabajado
  por correo electrónico.\

\

# Otros

- **Inscripción**. Para poder ser incluido en las Actas de Trabajos
  Prácticos, en caso de aprobar los trabajos prácticos, **es necesario
  haberse inscripto** en la materia (a través del[Sistema de
  Inscripciones de la Facultad](http://inscripciones.exactas.uba.ar/exactas/)) y haber completado la encuesta de
  evaluación docente.

\

- De acuerdo al
  Régimen de Correlatividades para las materias dictadas por el Departamento
  de Matemática,  para poder cursar  Análisis Numérico, **es
  necesario tener aprobados**  los  Trabajos Prácticos de
  Elementos de Cálculo Numérico, Medida y Probabilidad y Análisis
  Complejo; **así como** el Final de Probabilidades y
  Estadística.
- **Régimen de aprobación de los Trabajos Prácticos**. Para firmar
  los trabajos prácticos se deberá aprobar dos parciales, y presentar dos
  trabajos computacionales. Habrá un recuperatorio para cada parcial,
  mientras que para los trabajos prácticos se admitirán dos
  reentregas.\
- **Normas de seguridad**. Se recuerda que es **obligatoria** la
  lectura de las [normas de higiene y
  seguridad](http://www.dm.uba.ar/varios/normseg.html).
